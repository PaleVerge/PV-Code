# PV-Cpp

C++ 基础语法学习仓库，存放课堂作业和练习代码。

## 📂 目录

| 目录/文件 | 内容 |
|-----------|------|
| `类/` | 类与对象练习（Point、Student、Teacher、复数类、日期类、时间类、电梯类等） |
| `继承/` | 继承与派生（交通工具类、图形类、工人类、多重继承等） |
| `多态/` | 多态与虚函数（动态多态、虚函数、动物的叫声等） |
| `模板/` | 函数模板与类模板（动态数组类、队列模板等） |
| `运算符重载/` | 运算符重载（复数类、时间类、矩阵类、集合类） |
| `函数重载/` | 函数重载练习（area、cube、mini、数组排序等） |
| `指针/` | 指针与动态内存分配 |
| `字符串/` | 字符串操作练习 |
| `文件/` | 文件读写操作 |
| `栈/` | 栈的应用 |
| `输入输出/` | 输入输出基础练习 |
| `头文件/` | 标准库头文件使用示例 |
| `内联函数.cpp` | 内联函数练习 |
| `机器人.cpp` | 综合练习：机器人类 |
| `姓名排序.cpp` | 排序练习 |
| `求数组中最大元素.cpp` | 数组操作 |
| `在数组中查找一个给定值.cpp` | 查找算法 |

## 🔧 编译运行

```bash
g++ -std=c++17 <文件名>.cpp -o <输出名>
```
